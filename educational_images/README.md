The first two images describe the historical public full_v1 implementation. The new
roadmap does not update that code or imply that Agent staging has been implemented.
Implemented does not mean clinically validated. The 616 local v3 arousal candidates
across 151 recordings do not establish clinical event recall or precision. Research
priorities are suggestions, not measured maturity or expected improvement ratings.

Each PNG has a matching .prompt.md with generation prompts and source context.
Generated with built-in imagegen. All waveform drawings are schematic, not measured
HMC segments. These are implementation teaching aids, not clinical validation.

# V3 educational image creation notes

All seven V3 figures are generated by
[`scripts/generate_v3_educational_images.py`](../scripts/generate_v3_educational_images.py)
from [`reports/v3_evidence_summary.json`](../reports/v3_evidence_summary.json).
The script uses fixed NumPy seeds and Matplotlib's local DejaVu Sans font. Each
figure is exported as a 2560×1440 PNG for GitHub and an editable SVG.

No image-generation model was used. The deterministic vector/code-native path
was selected because labels, arrows, thresholds, and metrics must match sealed
scientific evidence exactly.

## Visual review record

The seven PNGs were inspected at full resolution. A second pass corrected:

- the Arousal legend/value collision;
- the eight-arm arrow/label spacing;
- clipped Wake/N3 category labels.

The final pass found no remaining text overflow, clipped category labels,
missing arrows, or unreadable color contrast at the generated resolution.
Figures containing waveforms state **Synthetic … — not clinical PSG** inside the
image. The figures are teaching aids; the machine-readable JSON remains the
numerical source of truth.

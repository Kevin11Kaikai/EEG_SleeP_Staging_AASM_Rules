# Public backup scope

This public tree contains source code, configuration, tests, two generated schematic
educational images, implementation/method documentation and aggregate metrics over
151 recordings. It excludes epoch labels/predictions, raw annotations, per-record
clinical outcomes, measured clinical waveform figures and full detector caches.

Detailed audit evidence and the compact reproducible scoring bundle remain in the
local workspace. The public aggregate matrix recheck does not reconstruct individual
annotation alignment or rerun PSG inference. Original cache resume/evaluate/ablate/audit
require the local full artifacts or a fresh official-data run.

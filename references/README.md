# Sources and versions

- Paper: https://arxiv.org/html/2605.22859v1 (paper-inspired implementation, not author code).
- HMC v1.1: https://physionet.org/content/hmc-sleep-staging/1.1/.
- YASA: https://github.com/raphaelvallat/yasa; runtime 0.6.5.
- `source_registry.json` records the hashes of the locally inspected source pages.
- Full cached paper/dataset web pages are not redistributed here; published report
  links point to their original sources. Page line references refer to the inspected
  local snapshot described in the registry.
- `third_party/` holds the exact installed YASA detection source referenced by the
  audit with its license. SciPy Welch links point to the official API documentation.
  The included source file is an audit reference,
  not runtime replacements for the locked dependencies.
